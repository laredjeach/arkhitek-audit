# Architecture Adjustments — Apply After Initial Build

These changes came in while the initial build was running. Apply once scripts/ files exist.

## Core principle shift
This is a **general-purpose audit engine**, not primarily a lead-gen pipeline.
"Point it at any data" is the primary use case — any URL list, CSV, or domain works as input.

---

## 1. leg2_audit.py — make this the CORE, accept any input

Add three input modes (in addition to reading leads/prospects.csv by default):

```python
# CLI additions
parser.add_argument("--csv", help="Any CSV file with a 'url' or 'website' column")
parser.add_argument("--urls", nargs="+", help="One or more URLs to audit directly")
parser.add_argument("--domain", help="Single domain to audit")
```

Input resolution priority: `--domain` → `--urls` → `--csv` → `leads/prospects.csv`

For `--csv`, auto-detect the URL column by checking for columns named: url, website, domain, URL, Website (in that order). All other audit logic (Firecrawl scrape → Claude → output) stays identical.

---

## 2. run_campaign.py — make Leg 1 optional

Add `--input` flag:

```python
parser.add_argument("--input", help="CSV or newline-separated URL file — skips Leg 1 if provided")
parser.add_argument("--legs", default="1,2,3", help="Which legs to run, comma-separated (e.g. '2,3' skips discovery)")
```

If `--input` is provided, skip Leg 1 and pass the file directly to Leg 2.

---

## 3. Add audit.py — the "point it at any data" entry point

New file: `scripts/audit.py`

```
python3 scripts/audit.py --url https://example.com
python3 scripts/audit.py --csv my_leads.csv
python3 scripts/audit.py --urls https://a.com https://b.com https://c.com
```

Behavior:
- Convenience wrapper that runs Leg 2 (audit) + Leg 3 (email draft) in sequence
- No Leg 1 (discovery) — you supply the targets
- Outputs: per-domain audit .md in runs/audits/ + email draft
- Works on ANY website regardless of niche, region, or whether it was discovered by the scraper

---

## 4. config/config.example.json — add input_mode

Add to the config:

```json
{
  "input_mode": "discovery",
  "_input_mode_options": "discovery (runs Leg 1 first) | direct (skip to Leg 2 with url_list)",
  "url_list": [],
  ...
}
```

When `input_mode` is `"direct"`, `run_campaign.py` reads `url_list` from config and feeds it to Leg 2 directly.
